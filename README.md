# 🧵 Мемори Тредс

Игра «найди пару» на чистом JavaScript: переворачиваешь карточки,
ищешь совпадения, ставишь рекорды. Без фреймворков, зато с Supabase,
офлайн-режимом и сборкой под Android.

🔗 Живая версия: https://memorythreads.vercel.app

## 🎮 Как играть
- Выбери размер поля: 4×4, 4×5 или 6×6
- Переворачивай карточки и ищи одинаковые картинки
- Чем меньше ходов и секунд — тем выше место в общем рейтинге
- Зарегистрируйся по нику, чтобы копить рекорды и выбрать себе эмодзи-аватарку

## ✨ Что внутри интересного
- Рейтинг и профили игроков на Supabase (PostgreSQL + Row Level Security)
- PWA: игра ставится на телефон и переживает обрывы сети
- Звуки и конфетти генерируются кодом (Web Audio API), без аудиофайлов
- Аватарки делают сами игроки: присылают фото — скрипт сам готовит карточки
- Сборка APK через Capacitor

## 🛠 Стек
- Фронтенд: HTML, CSS, ванильный JavaScript
- Бэкенд: Supabase (Auth, PostgreSQL, RLS)
- Хостинг: Vercel
- Мобильная версия: Capacitor
- Утилиты: Python + Pillow (обработка аватарок)

## 📁 Структура проекта
├── index.html            каркас страницы
├── styles.css            стили, темы, адаптивность
├── sw.js                 Service Worker: офлайн и автообновления
├── manifest.json         манифест PWA
├── capacitor.config.json настройки сборки APK
├── js/
│   ├── config.js         ВСЕ настройки игры в одном месте
│   ├── sounds.js         синтез звуков (Web Audio API)
│   ├── supabase.js       вход, профили, рекорды, рейтинг
│   ├── records.js        локальные рекорды (localStorage)
│   └── main.js           логика игры: поле, карточки, совпадения
├── images/               аватарки card01…cardNN, рубашки, иконки
├── update_avatars.py     скрипт обработки фото в аватарки
├── sync_www.py           скрипт обновления www перед сборкой APK
└── www/                  сборочная папка Capacitor (руками не трогать!)

## 🚀 Запуск у себя
1. `git clone https://github.com/minanytnik/memorythreads.git`
2. Открой папку в VS Code и запусти Live Server
   (или просто `python -m http.server 5500` в папке проекта)
3. Чтобы работали вход и рекорды — создай свой проект Supabase
   и пропиши ключи в `js/supabase.js` (таблицы: profiles, records)

## 🐍 Скрипты
**Добавить аватарки:** сложи фото в `avatars-source/` → `python update_avatars.py`
→ закоммить новые `cardNN.jpg` и обновлённый `config.js`.

**Собрать APK:** `python sync_www.py` → `npx cap sync android` → сборка в Android Studio.

## 🌐 Деплой
Веб живёт на Vercel: каждый пуш в main автоматически выезжает в прод.
Папку `www` руками не редактируем — её обновляет `sync_www.py`.
