# 🎮 Мемори Тредс

Классическая игра в мемори с современным веб-интерфейсом, системой достижений, профилями игроков и рейтингами. Построена на Vanilla JavaScript с использованием Supabase для бэкенда и работает как PWA с возможностью офлайн-режима.

## ✨ Возможности

- **Игровые поля**: 4×4, 4×5, 6×6 (плюс тестовое поле 2×3 через `?test=1`)
- **Система достижений**: 12 уникальных достижений с автоматической разблокировкой и всплывающими уведомлениями
- **Профили игроков**: эмодзи-аватарки, статистика (сыграно партий, среднее время, любимый размер) и сворачиваемый блок рекордов
- **Рейтинги**: таблицы лидеров по каждому размеру поля с возможностью просмотра чужих профилей
- **Геймплей**: таймер, подсчёт ходов, 3 темы оформления, 3 варианта рубашек карт
- **Звуковые эффекты**: через Web Audio API
- **PWA**: Service Worker с поддержкой офлайн-режима и автоматического обновления
- **Автоматизация**: Python-скрипты для обработки аватарок и синхронизации файлов
- **Безопасность**: Row Level Security (RLS) в Supabase
- **iOS-совместимость**: исправлен Service Worker для iOS
- **UX**: закрытие модальных окон по клику вне области и по клавише Esc

## 🛠 Технологии

- **Frontend**: Vanilla JavaScript, HTML5, CSS3
- **Backend**: Supabase (PostgreSQL, Realtime, Auth)
- **Звук**: Web Audio API
- **PWA**: Service Worker, Web App Manifest
- **Мобильное приложение**: Capacitor (для сборки APK)
- **Автоматизация**: Python

## 🗄 База данных

Используются 4 таблицы в Supabase с включённым Row Level Security (RLS):

| Таблица | Описание |
|---------|----------|
| `profiles` | Профили игроков с аватарками и статистикой |
| `records` | Рекорды игроков по разным размерам полей |
| `games` | История сыгранных партий |
| `achievements` | Информация о разблокированных достижениях |
